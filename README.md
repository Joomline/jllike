# JL Like

**Пакет плагинов социальных кнопок для Joomla 4, 5 и 6**

---

## Описание

JL Like — это набор плагинов для вывода современных социальных кнопок "Поделиться" в материалах Joomla и популярных компонентах:

- Content (статьи Joomla)
- K2
- ZOO
- EasyBlog
- VirtueMart
- JoomShopping
- ADSmanager

Плагин поддерживает популярные соцсети: Facebook, ВКонтакте, X (Twitter), OK.ru, Мой Мир, LinkedIn, Pinterest, LiveJournal, Blogger, Weibo, Viber, WhatsApp, Telegram, MAX, Threads, Reddit и др.

## Установка

1. Установите пакет через стандартный менеджер расширений Joomla.
2. Включите нужные плагины в разделе "Расширения → Плагины":
    - JL Like (content)
    - JL Like K2
    - JL Like for JoomShopping
    - JL Like for ADSmanager
    - JL Like for VirtueMart и др.
3. Настройте параметры отображения и автодобавления кнопок в каждом плагине.
4. Для ручного вывода используйте тег `{jllike}` в тексте материала.

## Обновления и миграция

### Версия 5.3.1 (08.10.2026)

**Новые возможности:**
- ✨ Кнопка «Поделиться в MAX» (официальная ссылка `https://max.ru/:share?text=…`), поддержка во всех стилях кнопок и в настройках порядка

**Исправления:**
- 🐞 Ошибка `jQuery is not defined` (Astroid, Cassiopeia и другие шаблоны без jQuery): при обновлении на сайте оставался старый `js/buttons.min.js` на jQuery, и Joomla подключала его вместо нового `buttons.js`. Теперь устаревшие файлы удаляются при установке
- 🐞 Joomla 6: фатальная ошибка `Class "Joomla\CMS\Filesystem\File" not found` при выборе картинки из текста, в K2, Zoo и при punycode
- 🐞 K2: фатальные ошибки из-за несуществующего `ClassLoader::register()` и необъявленного метода `getRoute()`
- 🐞 Кнопки VK и Facebook открывали два окна и прибавляли к счётчику 2
- 🐞 Кнопки не работали, если скрипт подключался после `DOMContentLoaded` (оптимизация JS в шаблоне)
- 🐞 Не работала опция «Запретить повторные лайки»
- 🐞 Кнопки с одинаковым порядковым номером пропадали
- 🐞 В `og:image` и ссылках попадал служебный хвост `#joomlaImage://...`
- 🐞 Двойное экранирование `og:title`/`og:description` (`&amp;quot;` в соцсетях)
- 🐞 Тег `{jllike}` в самом начале текста не распознавался
- 🐞 Неверная ссылка на материал, если сайт установлен в подпапку
- 🐞 Zoo: не загружался языковой файл
- 🐞 При включённых «фиксированных кнопках» и мобильных стилях панель на телефоне растягивалась на полэкрана и закрывала текст
- 🐞 Стили Minimal и Outlined: иконка LiveJournal отображалась сплошным кругом
- 🐞 Превью в настройках: выключенная и снова включённая кнопка не появлялась, не учитывались Threads и Reddit

**Безопасность:**
- 🔒 Все значения в HTML-атрибутах кнопок экранируются
- 🔒 Настройки для JS передаются через `json_encode` (кавычки в селекторах больше не ломают скрипты страницы)
- 🔒 Окно соцсети открывается без доступа к `window.opener`
- 🔒 Удаляется старый скрипт, который делал JSONP-запросы к сторонним API счётчиков
